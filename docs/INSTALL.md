# Установка, запуск и удаление RigForge

Руководство описывает установку готовых релизов **RigForge** на Windows 11 и Linux, управление автозапуском, обновление и удаление приложения.

---

## 1. Windows 11 (Рекомендуемый способ — установщик)

### Шаг 1. Скачивание релиза
Скачайте со страницы релизов файл **`RigForge-Setup-<version>-win-x64.exe`**.
Дополнительная установка `.NET Runtime` не требуется — рантайм уже упакован внутрь установщика.

> **Примечание по датчикам материнской платы и CPU:** для чтения температуры процессора, управления вентиляторами материнской платы (Super I/O) и подсветки ОЗУ по SMBus установите подписанный драйвер **PawnIO** ([pawnio.eu](https://pawnio.eu)). USB-контроллеры RGB, экраны Kraken и видеокарты по NVAPI работают без дополнительных драйверов. Перед первым запуском закройте конфликтующие программы (`SignalRGB`, `NZXT CAM`, `Armoury Crate LightingService`).

### Шаг 2. Пошаговая установка
Запустите `RigForge-Setup-<version>-win-x64.exe` и подтвердите запрос UAC:
1. **Выбор папки установки:** по умолчанию `C:\Program Files\RigForge`.
2. **Параметры запуска и ярлыков:**
   - **Start RigForge automatically when I sign in to Windows (Recommended)** — запускает фоновый демон в области уведомлений (трее) при входе в систему без повторных окон UAC, сразу применяя кривые охлаждения, виджеты СЖО и подсветку.
   - **Create a Desktop shortcut** — создаёт ярлык **RigForge** на Рабочем столе (ярлык в меню «Пуск» создаётся всегда).
3. **Завершение:** оставьте галочку **Launch RigForge**, чтобы сразу открыть панель управления.

### Шаг 3. Повседневная работа и управление автозапуском
- **Закрытие окна (`×`):** закрывает только графическое окно, освобождая оперативную память. Фоновый демон остаётся работать в системном трее и продолжает управлять охлаждением, экраном СЖО и подсветкой.
- **Запуск с ярлыка на Рабочем столе / в меню «Пуск»:**
  - если демон уже работает в трее — окно открывается мгновенно;
  - если автозапуск был выключен или демон был остановлен через `Exit` в трее — окно покажет экран запуска, автоматически поднимет демон без лишнего UAC и откроет дашборд.
- **Переключение автозапуска в любой момент:**
  1. Правый клик по иконке **RigForge** в системном трее → **Start with Windows**.
  2. Либо в окне приложения: вкладка **Devices** → кнопка **System & Startup** → переключатель **Start RigForge automatically when you sign in**.

### Шаг 4. Обновление и удаление
- **Обновление:** запустите новую версию `RigForge-Setup-<version>-win-x64.exe` поверх установленной. Мастер сам штатно остановит демон (вернув вентиляторы на управление прошивки на время обновления), обновит файлы и сохранит ваши профили и настройку автозапуска.
- **Удаление:** откройте **Параметры Windows → Приложения → Установленные приложения → RigForge → Удалить**:
  - На экране подтверждения по умолчанию **сохраняются** все пользовательские профили, кривые вентиляторов, раскладки холста и кастомные эффекты в `%LOCALAPPDATA%\RigForge`.
  - Если нужно удалить программу полностью вместе с настройками — отметьте галочку **Also delete my saved profiles, fan curves, layouts, and custom effects (`%LOCALAPPDATA%\RigForge`)**.
  - Перед удалением файлов деинсталлятор штатно останавливает демон, возвращая обороты вентиляторов/помпы и экран СЖО под управление прошивки/BIOS, после чего удаляет задачу Планировщика, ярлыки и файлы программы.

### Ключи командной строки установщика (Silent / Automation)
```powershell
# Тихая установка с автозапуском и ярлыком на рабочем столе
.\RigForge-Setup-0.1.0-win-x64.exe /S

# Тихая установка без автозапуска и без ярлыка на рабочем столе в кастомную папку
.\RigForge-Setup-0.1.0-win-x64.exe /S /AUTOSTART=0 /NODESKTOP=1 /D=C:\Apps\RigForge

# Тихое удаление с сохранением профилей в %LOCALAPPDATA%\RigForge
"C:\Program Files\RigForge\Uninstall RigForge.exe" /S

# Тихое удаление с полной очисткой профилей
"C:\Program Files\RigForge\Uninstall RigForge.exe" /S /PURGE=1
```

## 2. Linux (Debian/Ubuntu, Fedora, Arch/CachyOS, openSUSE)

### Установка из релизного архива
```bash
tar -xzf rigforge-linux-x64-0.1.0.tar.gz
cd rigforge-linux-x64
./deploy/linux/install-linux.sh
```

Скрипт устанавливает бинарные файлы в `~/.local/share/rigforge`, правила доступа `60-rigforge.rules` и модули `i2c-dev`, регистрирует пользовательский сервис `systemd` (`rigforge.service`) и добавляет ярлык **RigForge** в меню приложений рабочего стола (`~/.local/share/applications/rigforge.desktop`).

- Установка **без автозапуска** при входе в графическую сессию:
  ```bash
  ./deploy/linux/install-linux.sh --no-autostart
  ```
  При клике по ярлыку **RigForge** в меню приложений лаунчер `rigforge-open` сам запустит `rigforge.service` и откроет конфигуратор `http://127.0.0.1:5757/#/dashboard`.

### Удаление на Linux
```bash
# Удалить службу, правила udev, ярлык и файлы программы (профили в ~/.config/rigforge сохраняются)
./deploy/linux/uninstall-linux.sh

# Полное удаление вместе с профилями ~/.config/rigforge
./deploy/linux/uninstall-linux.sh --purge
```
